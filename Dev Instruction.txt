====================================================================
               AUTOMATE KARAOKE - DEVELOPER INSTRUCTIONS
====================================================================

--------------------------------------------------------------------
* EASIEST WAY: 1-CLICK LAUNCHERS (NO TERMINAL TYPING NEEDED)
--------------------------------------------------------------------
  1. Double-click "Start_Local.bat"
     -> Starts the local server immediately.

  2. Double-click "Start_Online_Stream.bat"
     -> Automatically launches both the local server AND the Cloudflare
        tunnel in separate windows. Copy your link from the tunnel window!

--------------------------------------------------------------------
1. HOW TO RUN LOCALLY & STREAM ON LOCAL WI-FI (MANUAL)
--------------------------------------------------------------------
Step 1: Open your terminal in the project folder and run:
    npm run dev

Step 2: You will see output like:
    > Local:   https://localhost:5173/
    > Network: https://192.168.x.x:5173/

Step 3: 
  * On your PC: Open https://localhost:5173/
  * On phone/tablet connected to the same Wi-Fi:
    Type your Network URL (e.g. https://192.168.1.50:5173) in Chrome/Safari.
    (If a certificate warning appears, click "Advanced" -> "Proceed to site").


--------------------------------------------------------------------
2. HOW TO STREAM PUBLICLY ONLINE (ANYWHERE IN THE WORLD)
--------------------------------------------------------------------
* You need TWO terminal windows open at the same time:

[TERMINAL 1] Keep your local app running:
    npm run dev

[TERMINAL 2] In a second terminal window, run Cloudflare Tunnel:
    npx cloudflared tunnel --url https://localhost:5173 --no-tls-verify

Step 3:
  * Look for the generated URL in Terminal 2:
    e.g. https://xxxx-xxxx-xxxx.trycloudflare.com
  * Open that link on ANY device, phone, or computer anywhere.


--------------------------------------------------------------------
3. HOW TO INSTALL AS A PWA (STANDALONE APP)
--------------------------------------------------------------------
  * When opening the app over HTTPS (localhost or Cloudflare tunnel),
    a purple floating "Install App" button appears at the bottom-right.
  * Click "Install App" to immediately trigger the 1-click install dialog.
  * Once installed, songs run in full-screen and work offline!


--------------------------------------------------------------------
4. USEFUL COMMANDS CHEATSHEET
--------------------------------------------------------------------
  npm run dev          -> Starts the development server with HTTPS
  npm run build        -> Checks TypeScript & builds production bundle
  npm run preview      -> Previews the built production bundle
